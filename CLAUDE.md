# manor

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `orrybaram/manor`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles use default label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` glossary; ADRs live at `docs/decisions/adr-NNN-*/index.md` (not `docs/adr/`). See `docs/agents/domain.md`.
