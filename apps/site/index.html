Pl. III Five rooms, five branches, no collisions.
Chapter II

A room per branch

Each workspace is its own git worktree, so four agents can rewrite four features without stepping on each other's files.

  • Open the diff, comment on a line, send it back to the agent.
  • Move a pane to another workspace when the work wanders.
  • Close the laptop. Sessions resume where they left off.
Chapter III

The east wing

Your laptop is one room. Remote hosts are the rest of the house. Agents keep running when you leave, and the same panes open from any desk or your phone.

Room 1local

This Mac

Your phone

Room 3ssh

The big box

A host server on any machine you can SSH into. Projects, workspaces and agents live there.

A host made for one project. It sleeps when idle and wakes when you open it.
