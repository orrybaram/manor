# Install `~/.manor/bin/manor` on startup, retire `manor-webview`, add bin dir to `PATH`

Replace `electron/webview-cli-script.ts` with an installer that follows the
`ensureHookScript` pattern in `electron/agent-hooks.ts`, and make the command reachable
from every Manor terminal.

## Implementation

1. `electron/paths.ts`: add `manorBinDir()` → `path.join(manorHomeDir(), "bin")`.
   Add a case to `electron/__tests__/paths.test.ts` matching the existing style.
2. New `electron/manor-cli-install.ts` exporting `ensureManorCli(): void`:
   - `fs.mkdirSync(manorBinDir(), { recursive: true })`.
   - Resolve the bundled JS the way `bundledAgentHookJsPath()` does:
     `path.join(__dirname, "manor-cli.js").replace("app.asar", "app.asar.unpacked")`.
     Read it; on failure (unit tests, dev from source) fall back to leaving any existing
     `manor.js` in place and log once at `warn` level — do **not** throw, startup must
     not depend on a build artefact.
   - Write `~/.manor/bin/manor.js` with mode `0o755`.
   - Write the shim `~/.manor/bin/manor` (mode `0o755`):
     ```bash
     #!/bin/bash
     # manor — Manor control CLI. Generated by Manor on startup; do not edit.
     exec node "$HOME/.manor/bin/manor.js" "$@"
     ```
   - If `~/.manor/bin/manor-webview` exists, `fs.rmSync` it. It was the ADR-053 bash
     wrapper that this command supersedes.
3. Delete `electron/webview-cli-script.ts`. In `electron/app-lifecycle.ts` replace the
   `ensureWebviewCli` import and call with `ensureManorCli`. Grep for any other reference.
4. `electron/terminal-host/session.ts`: in the `buildShellEnv(process.env, {...})`
   overrides next to `MANOR_PANE_ID`, prepend the bin dir:
   `PATH: \`${manorBinDir()}:${process.env.PATH ?? ""}\``. Read `buildShellEnv` first: if
   it already merges `process.env.PATH` in a way that makes this double-prepend on
   daemon restarts, dedupe by checking `process.env.PATH?.split(":").includes(manorBinDir())`.
   Note the terminal host is a separate bundle (`terminal-host-index.js`); confirm
   `./paths` is importable from there (it is used by `ShellManager` already; follow that import).
5. Add `electron/__tests__/manor-cli-install.test.ts`: with `HOME` pointed at a temp dir
   and a fake bundled `manor-cli.js`, assert `manor.js` and `manor` are written with the
   executable bit, the shim `exec`s the JS, and a pre-existing `manor-webview` is removed.
6. Manual check with the app running from `pnpm dev` or a packaged build: open a new
   terminal pane, run `which manor` and `manor --help`.

## Files to touch

- `electron/__tests__/paths.test.ts` — cover it
- `electron/manor-cli-install.ts` — new; `ensureManorCli`
